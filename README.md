## ストーリー

2年1組の主人公が、学校に忘れた宿題を取りに行くと、おばけに閉じ込められてしまいます。学校を元に戻して脱出しよう！

## PS1版の操作

- **スマートフォン：** 左側の仮想スティックで移動。光るマークをタップすると対象まで近づき、調べられます。
- **PC：** WASD／矢印キーで移動。近くの物はEキーで調べられます。
- 画面上部の「ヒント」「かばん」を使って謎解きできます。旧式のタンク操作も設定から選択可能です。
- おばけに触れてもゲームオーバーにはならず、びっくりする演出が起こります。

## 動作環境

WebGL対応のSafari・Chrome等。スマートフォンは横向きが遊びやすい構成です。音はゲーム内でオン／オフできます。

ゲーム内のJavaScript・画像等はブラウザに配信されるため、閲覧可能です。開発用の設計資料・管理記録・テストは非公開リポジトリで管理します。
