# おばけ第一小学校 ～夜の学校おばけポン！～

夜の小学校で、おばけになった文房具や家具をやっつける一人称シューティングゲームです。
小学生が「ねらってうつだけ」で遊べるように作っています。HTMLファイル1枚で動きます。

**あそぶ：** https://itommmm.github.io/obake-daiichi-shogakko/ （iPhoneはSafariで開いて横向き）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 本体（three.js 3D版） |
| `pad.html` | iPhone用コントローラー（「テレビで あそぶ」用）。向きとボタン操作をMacへ送る |
| `retro.html` | レトロ版（Pyxel 3.0）。こうていステージ1面＋ボス |
| `retro/main.py`・`retro/font.bdf` | レトロ版のソース（Python）と日本語フォント（使う文字だけ抜き出したもの） |
| `retro.pyxapp` | レトロ版をまとめたPyxelアプリ（Pyxelで直接起動できる） |
| `retro.webmanifest`・`retro-icon-*.png` | レトロ版をホーム画面に追加したときの全画面設定とアイコン |
| `index_2d.html` | 予備（Canvas 2D版）。ネットにつながらない場所や古い端末向け |

## 動作環境

| 項目 | 内容 |
|---|---|
| ブラウザ | Safari（Mac・iPhone・iPad）、Chrome、Edge（WebGL対応） |
| 端末 | パソコン（マウス＋キーボード）、スマホ・タブレット（横向き） |

## 主人公

プレイヤーは「5ねん1くみ おばけたいじたい」の小学生です。

- **オープニング**：スタートすると約7秒のオープニングが流れ、紅白帽・体操服・ランドセル姿の主人公が登場します（タップでスキップ。「もういちど」では流れません）
- **目線**：カメラは子どもの目の高さ（約76cm）。机がほぼ目の高さになり、おばけを見上げる形になります
- **武器**：おもちゃの水鉄砲。撃つと水の弧が飛び、しぶきが上がります。タンクの水位が残り弾数です（リロードは「みずを いれる」）
- **手**：体操服の袖と、ばんそうこうを貼った手で水鉄砲を握ります。ライトのスキルや停電中は、左手に黄色い懐中電灯が出てきます
- **HUD**：左下は「5ねん1くみ」の名札、右下は水のタンク

## 遊び方

1. タイトルで「かんたん／ふつう／むずかしい」を選び、「スタート！」を押します。
2. おばけが手前に来る前にうって「ポン！」とやっつけます。手前まで来られるとハートが1つ減ります。
3. 「のこり」を0にするとWAVEクリア。全5WAVEを進み、最後にボスをたおします。

## 水鉄砲のパワーアップ

**レベルアップ（ずっと続く）**：WAVEをクリアすると自動で進化します。

| レベル | 名前 | 効果 | 見た目 |
|---|---|---|---|
| Lv1 | ふつう | 1体に命中 | オレンジの水鉄砲 |
| Lv2（WAVE 2クリア） | ダブルノズル | 照準の近くの2体まで同時に命中 | ノズルが2本 |
| Lv3（WAVE 4クリア） | トリプル＆おおタンク | 3体まで同時に命中、タンク40発 | ノズル3本・大きなタンク |

| ワイド | 照準のまわり広くに、6体まで同時に命中 |

## 最終ボス「おばけこうしゃ」

とりつかれた学校の校舎そのものがボスです。

- **登場**：地面から突き上がって現れる。窓が目、昇降口が口、時計塔の針が暴走する
- **弱点**：目（黄色い輪）を撃つとクリティカルで3倍ダメージ
- **攻撃**（順番はランダム）

| 攻撃 | 内容 | 対処 |
|---|---|---|
| まどから つくえミサイル | 窓が光り、机・いす・ランドセルが飛んでくる | 撃ち落とす |
| テストようし ふぶき | テスト用紙の紙飛行機が降ってくる | 撃ち落とす |
| ろうかベロ | 口を開けて予告したあと、長い舌が伸びてくる | 予告中に口を4〜5回撃つと止められる（ボーナス）。チャイムのスキルでも止まる |
| チャイム衝撃波 | 時計塔の鐘が鳴り、衝撃波と雷。たましいが出る | たましいを撃って復活を防ぐ |

- **怒り**：体力が半分を切ると、柱の脚で立ち上がる。さらに減ると「さいごの あがき」で攻撃が速くなる
- **撃破**：連続爆発のあと校舎が沈み、空が夜明けの色に変わる

「チャイムでふっかつ！」イベント、アイテム（ハートのあめ・時計）、スコアとランクの仕組みは2D版と同じです。

| 項目 | 内容 |

| WAVE 2以降 | 近くのおばけが紙飛行機（理科室ではペン）を投げてくる。半分たおすと「ラッシュ！」で一気に出現。後半ほど少し速い（ボス戦は除く） |

## テレビで遊ぶ（Macでゲーム、iPhoneは光線銃コントローラー）

ゲームはMacで動かし、iPhoneはボタンだけのコントローラーにします。テレビとiPhoneに別々の画面が出ます。iPhoneの「あたま（上のはし）」をテレビに向けると、その方向に照準が出ます（光線銃方式。Steamの「Motioncade」の持ち方を参考）。

1. MacのSafariかChromeで https://itommmm.github.io/obake-daiichi-shogakko/ を開く
2. テレビに映すときは、Macのメニューバー「コントロールセンター」→「画面ミラーリング」→ LGテレビを選ぶ
3. タイトルの「テレビで あそぶ」を押す。QRコードと4けたの番号が出る
4. iPhoneのカメラでQRコードを読み取る（または `pad.html` を開いて番号を入れる）
5. 「はじめる」→「動作と方向へのアクセス」を「許可」
6. **ねらい合わせ**：テレビの真ん中に黄色い◎が出る。iPhoneをたてに持ち、あたまを◎に向けて「ここ！」を押す
7. iPhoneの「うつ」でスタート

| 持ち方 | 内容 |
|---|---|
| たて持ち（おすすめ） | 画面を上に向け、あたまをテレビへ。親指が下半分の「うつ」に来る |
| カメラ持ち | 画面を自分に向け、背面をテレビへ。「ここ！」を押したときの持ち方で自動判別 |

| iPhoneの画面 | すること |
|---|---|
| 下の大きいボタン「うつ」 | 撃つ（押しっぱなしで連射）。タイトル・結果画面ではスタート／もういちど |
| 上のボタン「わざ」 | 使えるわざを自動で出す（光っているときに使える） |
| iPhoneを強くふる | みずを入れる（リロード） |
| ◎ あわせる | ねらい合わせをやり直す（照準がずれたとき） |
| かんど | 照準の動きの大きさ（ひくい／ふつう／たかい）。画面のはしまでに必要な向きの角度が 30°／22°／15° |
| 上の小窓 | テレビのどこに照準があるかを点で表示 |
| Ⅱ | 一時停止／つづける |
| むずかしさ（タイトルのときだけ） | かんたん・ふつう・むずかしい |
| 上の表示 | ハートと水の残り |

| 項目 | 内容 |
|---|---|
| 向きの求め方 | deviceorientation（alpha・beta・gamma）から端末が指している方向を計算。向きの絶対値で決まるので、真ん中へ戻せば照準も真ん中へ戻る（傾きを積み上げる方式のずれを解消） |
| つなぎ方 | PeerJS（WebRTC）で、MacとiPhoneを直接つなぐ。つなぐ相手を探す仲介だけ、PeerJSの無料公開サーバー（0.peerjs.com）を使う |
| 前提 | MacとiPhoneがインターネットにつながっていること。同じWi-Fiだと遅れが小さい（確度：中） |
| 照準アシスト | 照準が近くのおばけへ吸いよせられ、当たり判定も広がる（大きなボスには吸いよせない） |
| 切れたとき | iPhoneは自動でつなぎ直す。Mac側はゲームを一時停止し、10秒ほどで「テレビで あそぶ」が元に戻る |
| 画面の消灯 | iPhoneのコントローラー画面は、操作中は暗くならないようにしている（Safari 16.4以降） |
| 注意 | 公開サーバーが混んでいる・止まっているときは、つながらないことがある（確度：中）。iPhoneの向きは磁気を使わないため、長く遊ぶと少しずつずれることがある → 「◎ あわせる」 |

## iPhoneだけで遊んでテレビに映す（AirPlay画面ミラーリング）

iPhoneとテレビには同じ画面が映ります。

iPhoneでゲームを動かし、画面をLGテレビ（AirPlay対応）やMacBook Airに映します。iPhoneを傾けて照準を動かします。テレビだけを見て遊べるように、iPhoneの画面は「場所で押し分ける」コントローラーになります。

| 操作 | 内容 |
|---|---|
| 右手側（画面の右6割）を押す | 照準の位置へ撃つ（押しっぱなしで連射） |
| 左手側（画面の左4割）を押す | わざ。使えるものを自動で選ぶ（スペシャル → 停電中ならライト → チャイム → ライト） |
| 2本指で同時に押す | 照準を真ん中に戻す |
| 水がなくなったとき | 自動でリロード |

**前提**：傾き操作は、HTTPSで公開したページでのみ使えます。claude.aiのリンク（アーティファクト）の中や、HTMLファイルを直接開いた場合は使えず、指での操作になります。

1. https://itommmm.github.io/obake-daiichi-shogakko/ を、iPhoneのSafariで開く
2. iPhoneを横向きにする（画面の縦向きロックはオフ）
3. タイトルの「かたむけて ねらう」を押し、「動作と方向へのアクセス」を「許可」
4. コントロールセンター →「画面ミラーリング」→ LGテレビ（またはMac）を選ぶ
5. 「スタート！」。照準がずれてきたら、2本指で押すか「◎」で真ん中に戻す（WAVEの始めにも自動で戻る）

| 項目 | 内容 |
|---|---|
| 照準の感度 | 左右±24°、上下±16°で画面の端まで |
| 方式 | ジャイロの回転の速さを積み上げる方式（横持ちでも向きが飛ばない）。少しずつずれるので「◎」で戻す |
| 遅れ | AirPlay画面ミラーリングの遅れ（0.1〜0.2秒程度、確度：中）がある |
| Macに映す場合 | macOS 12以降のMacはAirPlayの受信先になれる（「システム設定」→「一般」→「AirDropとHandoff」→「AirPlayレシーバ」をオン） |

## レトロ版（Pyxel 3.0）

ファミコン風のドット絵で作った別バージョンです。夜の校庭をスペースハリアーのように前へ進み、とんでくるおばけをみずでっぽうでたいじします。途中で中ボス「ランドセルだいおう」、最後に「おばけこうしゃ」と対決。たおすと夜が明けて、主人公が「あー よかった」。

**あそぶ：** https://itommmm.github.io/obake-daiichi-shogakko/retro.html （初回はPythonの読み込みで数秒〜十数秒かかります）

| 操作 | マウス・タッチ | キーボード |
|---|---|---|
| ねらう | 動かす・ゆびでなぞる（スマホでは照準がゆびの少し上に出る） | 矢印キー |
| うつ | おす（押しっぱなしで連射） | Z・スペース |
| よける | ねらう方向へ 主人公が左右に動く | 矢印キー |
| チャイム（ゲージ満タンで画面のおばけを全部たいじ） | 左下のベルをタップ | X |

**ステージの流れ（約1分40秒）**
| 区間 | 内容 |
|---|---|
| 前半（約38秒） | 1体・2体・横一列で 練習ぎみに |
| 中ボス | ランドセルだいおう（体力18）。紙くずを投げ、子分を呼ぶ |

## 技術仕様（3D版）

| 項目 | 内容 |
|---|---|
| 構成 | HTML 1ファイル。three.js r147（UMD版）をjsDelivrから読み込み |
| モデル | 画像素材なし。角丸ボックス・押し出し形状・回転体などをコードで組み立て |
| 素材（PBR） | MeshStandardMaterial。ランドセルは革（低ラフネス＋凹凸）、机・いすは木目、脚・ロッカーは金属（高メタルネス） |
| 照明 | 月光（青い平行光・影あり）、蛍光灯（点光源×2）、空の環境光、おばけの紫の光（手前3体に割り当て）、懐中電灯（スポットライト）、銃口・爆発の光 |
| 影 | 月光のリアルタイム影（PCFソフトシャドウ）。左の壁に本物の窓穴があり、窓枠の十字の影が床に落ちる |
| 空気感 | 距離の霧、窓からの光の筋、漂うほこり、足元の接地影 |
| 後処理 | ブルーム（目・オーラ・蛍光灯・銃口）、ACESトーンマップ、色調補正、ビネット、フィルムグレイン、被弾時のピンクのふち |
| 軽量化 | 部屋の静的メッシュを素材ごとに結合して描画回数を削減。光源の数を固定してシェーダーの作り直しを防止 |
| 画質の自動調整 | 2.5秒ごとにfpsを計測し、45fps未満なら一段下げる（高→中→低）。低ではブルームと光の筋を省略 |
| HUD | 3Dの上に2D canvasを重ねて描画（2D版と共通。名札と水タンクは3D版のみ） |
| オープニング | 主人公の3Dモデル（紅白帽・体操服・ランドセル・水鉄砲・懐中電灯）をコードで造形し、カメラを動かして演出。`startOpening()`／`opUpdate()`／`drawOpening()` |
| 音 | Web Audio APIでその場で合成 |
| 保存 | ハイスコア・難易度・画質をlocalStorageに保存（使えない環境では保存せずに動作） |
