# おばけ第一小学校 ～夜の学校おばけポン！～

雨の夜の第一小学校を舞台にした、3つの「こわかわいい」ゲームです。
3D版はシューティング、レトロ版は連続ステージ、PS1版は なぞとき脱出。どれからでも遊べます。

**あそぶ：** https://itommmm.github.io/obake-daiichi-shogakko/ （iPhoneはSafariで開いて横向き）

## ストーリー（3D版・レトロ版・PS1版 共通）

**わすれものを とりに きたら、がっこうが おばけに…！**

2ねん1くみの ぼくは、あした 出す しゅくだいの ノートを つくえに わすれた。夜の学校に とりに いくと、入ったとたん ドアが「バタン！」と しまって とじこめられる。学校は おばけに のっとられていた。「がっこうを もとに もどせば でられるかも！」――もどすのに むちゅうに なった ぼくは、ぜんぶ もとに もどして ドアが あくと、うれしくて そのまま かえってしまう。しゅくだいは つくえの 中に のこったまま。つぎの あさ、せんせい「しゅくだいは？」 ぼく「あっ！！ わすれた！」

- しゅくだいは とちゅうで 1回 見える（「あとで あとで！」と あとまわし）。さいごに ぼくは 思い出さない
- 3D版・レトロ版は みずでっぽうで へやを もどす。PS1版は うたずに、なぞときで へやを もどす
- これは**同じ夜の できごとを、ちがう あそびかたで 語り直した3作品**です。続編同士ではありません
- せりふの 一覧は [STORY.md](STORY.md)、共通設定と今後の制作ルールは [docs/STORY_BIBLE.md](docs/STORY_BIBLE.md)、3作品の流れは [docs/STORY_FLOW.md](docs/STORY_FLOW.md)

### 2026-11-08 遊びやすさの調整

## 主人公

プレイヤーは「2ねん1くみ おばけたいじたい」の小学生です。

- **オープニング**：スタートすると約7秒のオープニングが流れ、紅白帽・体操服・ランドセル姿の主人公が登場します（タップでスキップ。「もういちど」では流れません）
- **目線**：カメラは子どもの目の高さ（約76cm）。机がほぼ目の高さになり、おばけを見上げる形になります
- **武器**：おもちゃの水鉄砲。撃つと水の弧が飛び、しぶきが上がります。タンクの水位が残り弾数です（リロードは「みずを いれる」）
- **手**：体操服の袖と、ばんそうこうを貼った手で水鉄砲を握ります。ライトのスキルや停電中は、左手に黄色い懐中電灯が出てきます
- **HUD**：左下は「2ねん1くみ」の名札、右下は水のタンク

## 遊び方

1. タイトルで「かんたん／ふつう／むずかしい」を選び、「スタート！」を押します。
2. おばけが手前に来る前にうって「ポン！」とやっつけます。手前まで来られるとハートが1つ減ります。
3. 「のこり」を0にするとWAVEクリア。全8WAVEを進み、最後にボスをたおします。

## スキル

### 3D版：わざ・ラッシュ・演出の調整

- スペシャルとチャイムはボスのガードを解除してからダメージを与える。既存のガード解除後の「チャンス」も発生する。
- ガードの残り時間はボスが停止中でも減る。一時停止・開始演出中は減らない。
- ラッシュの追加敵は空き枠へ0.22秒間隔で出現する。通常敵の最大同時出現数と残り目標数を超えないよう待機し、次のWAVEへは持ち越さない（投げ物は通常敵の枠とは別）。
- 突進予告は「かんたん」1秒・「ふつう」0.75秒・「むずかしい」0.55秒。赤い「▼ つっこんでくる！」で対象を示す。
- 一時停止画面の「ゆれ・ピカピカ」で演出を切り替えられる。「ひかえめ」はプレイ中のカメラの揺れ、雷と全画面の点滅、蛍光灯のちらつき、銃口・爆発の照明を抑える。被弾時の色変化も弱めるが、敵の予告と命中・撃破の表示は残す。
- 演出設定は端末に保存。未設定の場合はOSの「視差効果を減らす」に従う。難易度・敵の体力・当たり判定は変わらない。

| スキル | 効果 | 待ち時間 |
|---|---|---|
| ライト（Z） | 5秒間、照らしたおばけを止める。照らしたおばけへの攻撃は2倍。左手の懐中電灯から本物の光が当たる | 14秒 |
| チャイム（X） | すべてのおばけを奥へ吹き飛ばし、少しのあいだ止める | 20秒 |
| スペシャル（C） | ゲージが満タンのときに使用。画面のおばけを全滅（ボスは12％ダメージ） | ゲージ制 |

## ステージ（全8WAVE）

### 追加した攻略・よりみち（2026-11-08）

- **ランドセロの弱点**：ふたが周期的に開く。黄色い輪で示した中を撃つと一発で倒せて +150点。閉じていても通常どおり倒せる。
- **つくえタワー**：近くの机といすが2.5秒かけて合体。合体前にどちらかを倒すと +300点。机を倒すといすも巻き込み、いすを倒すと机に追加ダメージ。間に合わなくても倒せるが、机が大きく・かたくなる。
- **撃てる学校の仕掛け**：各通常WAVEに1回、青い輪のついた蛇口／体育館のボールかごを撃つと、画面の敵を止めてまとめてダメージ。仕掛け自体は3Dで配置し、水しぶきや転がるボールで反応を表示。
- **WAVE 2のあとに二択**：「りかしつ」か「よりみち おんがくしつ」を選ぶ。音楽室ルートは体育館の部屋を使い、楽器おばけが出る。全8WAVEのままで、WAVE 3の部屋・敵・次のWAVEのごほうびが変わる。理科室は「パワー2ばい」、音楽室は「まとめうち」が10秒。通常のWAVE 5の音楽会も残る。
- **よりみちの とくせい**：えらんだ道で、そのあとずっと うち方が変わる。りかしつ＝「こおる みず」（あたった おばけが 1.6秒 おそくなる）、おんがくしつ＝「おとの わ」（たおすと まわりの おばけが 1.1秒 とまる）。
- **選び方**：左右をタップ、1・2／左右キー、または傾き操作・テレビ用コントローラーで左右をねらって「うつ」。選択中は時間が減らない。
- **ボスの予告**：中ボスはテスト／仲間呼びを事前表示。最終ボスは攻撃の1.2秒前に、何が来るか・何を撃つかを表示。ベロの口を撃って止める仕組みも残す。

| WAVE | 場所 | 進み方 | 特徴 |
|---|---|---|---|
| 1 | 2-1 きょうしつ | その場で迎え撃つ | ランドセロ・いすわらし・つくえんぼが登場 |
| 2 | 2かい ろうか | **前進**（廊下を走る） | 停電で照明が消える。半透明のゆうれい |
| 3 | りかしつ | その場で迎え撃つ | 緑のフラスコは爆発して周りを巻き込む。ペン立ては分裂 |
| 4 | げんかん | **横移動**（下駄箱沿い） | 下駄箱から「うわばき」が飛び出す。敵は画面の右から流れてくる |
| 5 | よるの おんがくかい（体育館） | その場で迎え撃つ | 幕の開いた舞台で、ゆうれいの指揮者とひとりでに鳴るピアノ。楽器のおばけが音を鳴らしながら飛んでくる。BGMは不気味なワルツ |
| 6 | よるの こうてい | **高速前進**（スペースハリアー風） | 空を飛ぶおばけ、集中線、走る揺れ |
| 7 | 2-1 きょうしつ | その場で迎え撃つ | 中ボス：ロッカーだいおう |
| 8 | さいごの たたかい（校庭） | ボス戦 | 最終ボス：おばけこうしゃ |

- **ボスの ガード（3D版）**：ロッカーだいおうは 数秒ごとに ドアを しめて 水が きかなくなる（0.9秒前に予告）。こうげきの直後（ドアが あいた時）は ダメージ2ばい。おこると テストようしが 1→2→3まい。おばけこうしゃは 立ちあがったあと 約8秒ごとに 2.2秒 かたくなる（ダメージ 1/4、窓が水色）。ベロは さいごの あがきで 5回 当てないと 止まらない

## ★3つ・わざ・ボスの チャンス・おばけずかん（2026-11-08）

- **WAVEごとの ★3つ**：クリア、ノーダメージ、「わざ」を 3かい（ボスは 2かい）。クリア画面で ★が 1つずつ出る。いちばん よかった ★は WAVEごとに ほぞんされ、タイトルに 合計が出る。結果画面に その回の ★の数が出る。
- **わざ**（とくべつな たおし方）：ふたが あいた ランドセル、がったいを とめる、フラスコの ばくはつに まきこむ、じゃぐち・ボールかごを うつ、ライトで てらして たおす（ライト1回に 1かい）、とんでいる うわばき・ボール、がっきが なった しゅんかん、ボスの チャンスに あてる、ベロ ストップ。わざが きまると 一しゅん とまって 金色の わが出て、スペシャルゲージが ふえる。WAVEの はじめに その面の わざの ヒントが出て、プレイ中は 上に「わざ ★★☆」が出る。
- **ボスの チャンス**：ロッカーだいおう・おばけこうしゃの ガードが とけた時と、ベロを とめた時に「いまだ！ うて！」。すこしの あいだ スローになり、ボスの まわりに 金色の わが出て、ダメージ 2ばい。（ロッカーの「くちが あいた時 2ばい」は これに おきかえ）
- **おばけずかん**：タイトルの「おばけずかん」から。たおした おばけの なまえ・たおし方・たおした かずが出る。まだ会っていない おばけは シルエット。絵が ない おばけは ゲームの3Dモデルを その場で うつして出す。新しい おばけに会うと クリア画面に「ずかんに あたらしい おばけ！」。

## 最終ボス「おばけこうしゃ」

とりつかれた学校の校舎そのものがボスです。

- **登場**：地面から突き上がって現れる。窓が目、玄関が口、時計塔の針が暴走する
- **弱点**：目（黄色い輪）を撃つとクリティカルで2倍ダメージ
- **攻撃**（順番はランダム）

| 攻撃 | 内容 | 対処 |
|---|---|---|
| まどから つくえミサイル | 窓が光り、机・いす・ランドセルが飛んでくる | 撃ち落とす |
| テストようし ふぶき | テスト用紙の紙飛行機が降ってくる | 撃ち落とす |
| ろうかベロ | 口を開けて予告したあと、長い舌が伸びてくる | 予告中に口を4〜5回撃つと止められる（ボーナス）。チャイムのスキルでも止まる |
| チャイム衝撃波 | 時計塔の鐘が鳴り、衝撃波と雷。たましいが出る | たましいを撃って復活を防ぐ |

- **怒り**：体力が半分を切ると、柱の脚で立ち上がる。さらに減ると「さいごの あがき」で攻撃が速くなる
- **撃破**：連続爆発のあと校舎が沈み、空が夜明けの色に変わる

「チャイムでふっかつ！」イベント、アイテム（ハートのあめ・時計）、スコアとランクの仕組みもあります。

## バランス調整（プレイテスト結果より）

自動プレイ（iPhone横画面サイズ、腕前2種×難易度3種）で通しテストし、次のように調整しました。

| 項目 | 内容 |
|---|---|
| WAVE 2以降 | 近くのおばけが紙飛行機（理科室ではペン）を投げてくる。半分たおすと「ラッシュ！」で一気に出現。後半ほど少し速い（ボス戦は除く） |
| WAVEの長さ | 目標数を約1.3倍（1WAVE 20〜30秒前後） |
| ボス前 | 「ほけんしつで ぜんかいふく！」でハートが満タンになる |
| 中ボス | 体力175（パワーアップ込みで調整）。攻撃間隔を少し長く |
| 最終ボス | 体力400（パワーアップ込みで調整）、目のクリティカルは2倍。手下と紙ふぶきを減らし、ベロの予告を3秒に延長。立ち上がり時にハートのあめが2つ落ちる |

## テレビで遊ぶ（Macでゲーム、iPhoneは光線銃コントローラー）

ゲームはMacで動かし、iPhoneはボタンだけのコントローラーにします。テレビとiPhoneに別々の画面が出ます。iPhoneの「あたま（上のはし）」をテレビに向けると、その方向に照準が出ます（光線銃方式。Steamの「Motioncade」の持ち方を参考）。

1. MacのSafariかChromeで https://itommmm.github.io/obake-daiichi-shogakko/ を開く
2. テレビに映すときは、Macのメニューバー「コントロールセンター」→「画面ミラーリング」→ LGテレビを選ぶ

5. 「はじめる」→「動作と方向へのアクセス」を「許可」
6. **ねらい合わせ**：テレビの真ん中に黄色い◎が出る。iPhoneをたてに持ち、あたまを◎に向けて「ここ！」を押す
7. iPhoneの「うつ」でスタート

### 2026-11-08 操作の作り直し

子どもがRoblox／Minecraftに慣れている場合、旧タンク操作・固定カメラの方向切替は混乱するため、**マイクラ風を初期操作**に変更した。

- 追従カメラ：マウス・右スワイプで視線の方向と高さを変更。壁や家具に当たるとカメラが自動で近づく。
- 移動：WASD／矢印、スマホはアナログスティック。視点に対する前後左右で操作。左右キーが「回転」ではなく「横移動」になる。
- 操作補助：近くに調べられるものがあると「しらべる！」ボタンを目立たせる。
- 旧操作：タイトルまたはもちものの「そうさ」でクラシック（旧タンク＋固定カメラ）に切替。
- 設定：`obake-ps1-controls-v3` にモードを保存。従来の`obake-ps1-mode`は読み込まず、更新後の初回は新操作を標準とする。ゲームのセーブデータキー`obake-daiichi-ps1-v2`は変更しない。
- 実装：`ps1/controls.js` を追加、`ps1/logic.js`のカメラ・移動・入力を更新。3D版とレトロ版は未変更。
