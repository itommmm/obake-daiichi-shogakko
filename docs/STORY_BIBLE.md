# おばけ第一小学校｜共通ストーリーバイブル

作成日：2026-11-08。改訂：2026-11-08（しゅくだい・とじこめ・PS1なぞとき脱出に変更）。対象：3D版・レトロ版・PS1版。**今後の設定の正本**。
せりふの一覧は [STORY.md](../STORY.md)。

## 共通のあらすじ

**わすれものを とりに きたら、がっこうが おばけに…！**

**2年1組**の子どもが、あした出す**しゅくだいのノート**を教室の机に忘れた。雨の夜の第一小学校へ取りに行くと、入ったとたんドアが「バタン！」と閉まって閉じ込められる。学校はおばけにのっとられていた。「がっこうを もとに もどせば でられるかも！」――元に戻すのに夢中になった子どもは、全部戻してドアが開くと、うれしくてそのまま帰ってしまう。しゅくだいは机の中に残ったまま。次の朝、先生「しゅくだいは？」→「あっ！！ わすれた！」

## 変更しない基本設定

| 項目 | 正本 |

| 動機 | しゅくだいのノートを取りに夜の学校へ来た |
| 閉じ込め | 学校に入ったとたんドアが閉まる。学校を元に戻すとドアが開く（3作品共通） |

| 時刻 | 雨の夜から次の朝へ。PS1風の年号表示は演出であり確定年号ではない |
| おばけ | いたずら好きな「こわかわいい」存在。PS1版では接触してもダメージがなく、脅かすだけ。異変の原因・黒幕は決めない |

## 敵とボス

- **ランドセロ**：おばけが取りついたランドセル。
- **いすわらし、つくえんぼ、うわばき**：同じ異変で動く道具。
- **ロッカーだいおう**：ロッカー型の強いおばけ。3D版は教室、PS1版は体育館（倒せない。ふえで静める）、レトロ版は廊下。
- **おばけこうしゃ**：校舎そのものが姿を現したもの。3D版では最終ボス。レトロ版では第1面で校舎の顔を退けても、室内の異変が続く。
- **おばけピアノ、おばけとびばこ等**：各部屋のいたずらの中心。学校全体の黒幕を追加しない。

## 作品同士の関係

**同じ夜のできごとを異なる遊び方で語り直した作品。続編や厳密な時系列ではない。**

1. **3D版：正面突破。** 教室から8WAVE。WAVEごとに「○○が もとに もどった！」。最後はおばけこうしゃ。
2. **レトロ版：校庭からの連戦。** こうてい → ろうか → おんがくしつ・りかしつ → たいいくかん。
3. **PS1版：なぞとき脱出。** 玄関で閉じ込められ、教室（こくばん）・職員室（とけい）・体育館（ふえ）の3つを元に戻して玄関から出る。

別作品のクリア状況を同一時間軸で引き継ぐ必要はない。

## 今後の追加開発ルール

- 新ステージ・敵・演出は「おばけにのっとられた学校を元に戻す」に結びつける。クリアの言葉は「○○が もとに もどった！」。
- しゅくだいは途中で思い出させない（オチが消えるため）。
- ルートごとの攻略方法は維持し、キャラクター名・学年・事件の動機は統一する。
- 長い説明は増やさず、短いセリフ・掲示物・演出で補う。
- 導入は小学2年生の読む速度に配慮し、PS1版はオープニング・エンディングともボタンで進める（自動で終わらせない）。
- PS1版のおしまいの画面は、とびらが開き朝日が差す。視覚効果を減らす設定に対応する。
- 3D版の目線は1.00m。命中判定などを含めブラウザプレイで体感を確認する。
- 実際に行えない操作をセリフで命じない。
- 新たな黒幕、年号、主人公の名前などは必要になるまで確定しない。
- コードで追加した文言は画像内の文字・フォント・モバイル表示も確認する。

## PS1版のコミカルホラー演出（2026-11-08）

- おばけは殺傷しない。突然の顔・音・リアクションで笑わせる。驚かした後は距離を取る。
- 10種類の場所別ハプニングを配置。教室・廊下・職員室・体育館・玄関の固有音が鳴る。
- 謎解き中の長いメッセージを驚かしで上書きせず、クールダウンを設ける。
- おまもりのはっぱは一時的に安全な探索時間をつくり、必要ならヒントボタンで謎を進められる。
- 音は外部ファイルなしのWebAudio合成。音量制限・ミュート・動き軽減に配慮する。
- しゅくだいのオチと2年1組の主人公設定は変えない。
