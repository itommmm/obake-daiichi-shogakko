# おばけ第一小学校｜共通ストーリーバイブル

作成日：2026-11-08。対象：3D版・レトロ版・PS1版。**今後の設定の正本**。
この文書は、実装済みの事実と、新たに統一のため採用した物語設定を区別する。

## 共通のあらすじ

忘れ物を取りに雨の夜の第一小学校へ戻った**2年1組**の子ども。勝手に鳴った夜のチャイムをきっかけに、学校の道具や校舎がおばけに取りつかれた。水鉄砲と勇気で異変を鎮め、時計とチャイムの混乱が収まって朝を迎える。

## 変更しない基本設定

| 項目 | 正本 |
|---|---|
| 主人公 | 2年1組の小学生。名前・性別は固定しない。「おばけたいじたい」の呼び方は残す |
| 動機 | 忘れ物を取りに学校へ来た |
| 時刻 | 雨の夜から夜明けへ。PS1風の1996年表示は演出であり確定年号ではない |
| 異変 | 落雷で校舎の時計が狂い、夜のチャイムが繰り返し鳴って学校の道具や校舎がおばけに取りつかれた |
| おばけ | いたずら好きな「こわかわいい」存在。死者や悪意の強い怪物とは断定しない |
| 水鉄砲 | おばけを「ポン！」と退け、異変を弱める。複雑な魔法設定は足さない |
| おふだ | PS1版では3枚集めると学校が静まり出口が開く。貼る操作は存在しない |
| 結末 | 学校の異変が収まり、朝になる。忘れ物は後日取りに来る展開も許容 |

## 敵とボス

- **ランドセロ**：おばけが取りついたランドセル。
- **いすわらし、つくえんぼ、うわばき**：同じ異変で動く道具。
- **ロッカーだいおう**：ロッカー型の強いおばけ。3D版は教室、PS1版は体育館、レトロ版は廊下に登場。出現場所はルートによって異なる。
- **おばけこうしゃ**：校舎そのものが姿を現したもの。3D版では最終ボス。レトロ版では第1面で校舎の顔を退けても、室内の異変が続く。
- **おばけピアノ、おばけとびばこ等**：各部屋のいたずらの中心。学校全体の黒幕を追加しない。

## 作品同士の関係

**同じ夜の事件を異なるルート・遊び方で語り直した作品。続編や厳密な時系列ではない。**

1. **3D版：正面突破。** 教室から出発し、8WAVEを進み、ロッカーだいおうからおばけこうしゃへ。学校が元に戻り、忘れ物を思い出す。
2. **レトロ版：校庭からの連戦。** 校庭の校舎の顔を退けても異変は続く。廊下、音楽室・理科室、体育館を攻略し、夜明けを迎える。
3. **PS1版：おふだの探索。** 教室・職員室・体育館でおふだを集め、校門を開けると学校が静まり朝になる。

別作品のクリア状況やボス撃破を、同一時間軸で引き継ぐ必要はない。

## 今後の追加開発ルール

- 新ステージ・敵・演出は、共通の夜の異変に結びつける。
- ルートごとの攻略方法は維持し、キャラクター名・学年・事件の動機は統一する。
- 長い説明は増やさず、短いセリフ・掲示物・演出で補う。
- 導入は小学2年生の読む速度に配慮し、PS1版はボタンで進められる。
- PS1版のクリア演出は門が開き朝日が差す。視覚効果を減らす設定に対応する。
- 3D版の目線は1.00m。命中判定などを含めブラウザプレイで体感を確認する。
- 実際に行えない操作をセリフで命じない（例：「おふだをはる」）。
- 新たな黒幕、年号、主人公の名前などは必要になるまで確定しない。
- コードで追加した文言は画像内の文字・フォント・モバイル表示も確認する。
