# PS1版：固定カメラ＋スティック操作の確認

対象：PS1版のみ。3D版・レトロ版には変更を加えない。

## 実装・静的検査
- 固定カメラを使用。廊下などでは従来の固定アングルの切り替えを維持。
- スティック・WASD／矢印キーは画面の上下左右に直接移動。
- カメラ切り替え前に入力を開始しても、倒し続ける間は世界方向が反転しない。スティックを一度離すと新カメラ方向を取得。
- 右スワイプとマウスルック、Pointer Lockを要求するコードを削除。
- 旧タンク操作は任意で選択できる。
- 既存の探索・謎解き・コミカルなおどかし・音・セーブは維持。
- `tools/test_ps1.js` で固定カメラ・スティック・クラシック・カメラ境界の移動を回帰検査。

## 手動プレイが必要な項目
1. スマホで左スティックを上・下・左・右・斜めに動かすと画面の方向どおり移動する。
2. スティックを離すとすぐに止まり、指が枠外へ移動しても操作が暴走しない。
3. 右スワイプではカメラが動かない。右側の「しらべる」「もちもの」ボタンは操作可能。
4. 廊下の固定カメラ切り替えで、倒し続けたまま急に逆走しない。
5. PCでWASD／矢印キー操作が動き、マウスカーソルが拘束されない。
6. 旧タンク操作への切り替えと復帰。
7. 全ての扉・アイテムへの到達、暗証番号517、黒板・時計・体育館の謎、エンディング。
8. iPhone・Androidの縦／横向きとタッチ操作の被り、スクロール、音量。
9. 旧セーブの引継ぎ、操作モード設定の引継ぎ。

GitHub Pagesの配信成功や構文検査は、上記の実機プレイテストの代わりにはならない。
