# PS1版：操作リニューアル検証チェックリスト

対象：PS1版だけ。元の3D版・レトロ版は変更しない。

## 自動・静的検査
- JavaScript／HTML／CSSの構文と参照先を検査する。
- `tools/test_ps1.js` で新操作・旧タンク操作・追従カメラ・固定カメラ・アイテム／ドアの到達性・謎解き・セーブを検査する。
- カメラと家具・壁の接触時に、キャラクターが視界から突然消えないことを確認する。
- 旧セーブ（v2）が引き続き読み込まれることを確認する。

## PC手動テスト
1. 新規起動で「そうさ：マイクラ風」になっている。
2. ゲーム画面をクリックした後、マウスで自由に見回せる。マウスロック未対応の場合はドラッグで回る。
3. W/Sは視点方向の前後、A/Dは視点方向の左右に移動。Shiftで走れる。
4. 廊下・玄関など狭い場所で、壁越しにカメラが飛び出さない。
5. Eで調べる／もちもの／暗証番号操作／全謎解きを終えられる。
6. もちもの画面で旧クラシックに切替→タンク操作→新操作へ戻せる。
7. 終了・再起動後に選んだモードが維持される。

## iPhone／Android手動テスト
1. 左スティックを倒すとその方向に移動、離すとすぐ停止。指がスティックの外に出ても正常。
2. 右半分のスワイプで視点を移動。左スティックと同時に右スワイプできる。
3. 「しらべる」「もちもの」「♪」が画面端でも押せる。
4. スマホを縦向き・横向きにしてボタンやヒントが重ならない。
5. ブラウザのスクロール・ズームが暴発しない。アプリ切替後は入力が離れる。
6. おばけに触れても死亡せず、全謎解きが進められる。

## 未確認の扱い
手動テストや実機操作ができていない部分は「未確認」と明記する。GitHub Pagesのデプロイ成功だけでプレイテスト成功とは扱わない。
