# 3作品のストーリーフロー

共通設定：雨の夜、忘れ物を取りに来た**2年1組の子ども**が、勝手に鳴ったチャイムのあと動き出した学校用品と遭遇する。3作品は同じ事件の**独立した別ルート**。

## 3D版（正面突破）

タイトル（忘れ物の夜） → 導入（チャイムと動く学校用品） → WAVE1・2（教室・廊下） → **WAVE3で理科室／音楽室に分岐** → WAVE4玄関 → WAVE5体育館 → WAVE6校庭 → WAVE7ロッカーだいおう → WAVE8おばけこうしゃ → 校舎が戻り朝になる → 忘れ物を思い出す。

- 2ルートとも同じ終盤に合流する。操作・獲得特性は従来どおり。
- ゲームオーバー・再挑戦は同じ夜の挑戦のやり直し。

## レトロ版（校庭からの連戦）

タイトル（2年1組の忘れ物の夜） → 第1面校庭・おばけこうしゃ → **校内にはおばけが残る** → 第2面廊下・ロッカーだいおう → 第3面音楽室・理科室・おばけピアノ → 第4面体育館・おばけとびばこ → 朝、学校が元に戻る → 忘れ物を思い出す。

- 第1面の校舎の顔を退けても異変は続く。面数・中ボス・攻撃はそのまま。
- ゲームオーバー後は従来どおり同じステージ頭から再開。

## PS1版（探索・おふだ）

タイトル（忘れ物の夜） → 導入（チャイムで異変） → 教室のおふだ → 廊下を探索 → 職員室のおふだ／体育館のボスを倒しておふだ → 玄関 → **おふだ3枚所持で校門が開く** → 学校が静まり朝になる。

- 職員室と体育館の訪問順・寄り道はプレイヤーの自由。
- おふだを「貼る」操作はない。集めることがクリア条件。
- セーブ／ロード／ゲームオーバー／再挑戦は変更しない。

## 検証基準

各ゲーム単独で「来校理由→異変→目的→解決→朝」が理解できる。別作品との連動やクリア条件の共有は不要。ゲームプレイの数値設定に変更を加えない。
