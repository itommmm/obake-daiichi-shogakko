# 3作品のストーリーフロー

共通設定：雨の夜、しゅくだいを取りに来た**2年1組の子ども**が、学校に入ったとたん閉じ込められる。おばけにのっとられた学校を元に戻すとドアが開き、帰る。しゅくだいは机に残ったまま（次の朝「あっ！！ わすれた！」）。3作品は同じ夜の**独立した別ルート**。詳しいせりふは [STORY.md](../STORY.md)。

## 3D版（正面突破）

タイトル（わすれものを とりに きたら…） → オープニング（しゅくだい → 「バタン！」とじこめられた → ランドセルが動く → もとに もどせば でられるかも） → WAVE1教室（クリア後「あ、しゅくだい… あとで あとで！」） → WAVE2廊下 → **WAVE3で理科室／音楽室に分岐** → WAVE4玄関 → WAVE5体育館 → WAVE6校庭 → WAVE7ロッカーだいおう → WAVE8おばけこうしゃ → 学校が戻りドアが開く → 帰る → 机のしゅくだい → 次の朝。

## レトロ版（校庭からの連戦）

タイトル → オープニング紙芝居（学校 →「バタン！」→ 教室のランドセル「ガタガタッ」→「もとに もどすぞ！」） → 第1面こうてい（校舎の顔は静まるが、なかにもおばけ） → 第2面ろうか（2-1教室の前で「あとで あとで！」） → 第3面おんがくしつ・りかしつ → 第4面たいいくかん → 全部戻る → 帰る → 机のしゅくだい → 次の朝。

## PS1版（なぞとき脱出）

タイトル → ボタンで読む導入（しゅくだい →「バタン！」とじこめられた → のっとられている → もとに もどせば でられるかも） → 玄関スタート → 2年1組（自分の机でしゅくだいを見つけて「あとで あとで！」／こくばんけしで黒板の落書きを消す） → 職員室（かぎ・とまった時計にでんち） → 体育館（番号ロック517・ステージでふえ） → 玄関のドアが開く → 帰る → 机のしゅくだい → 次の朝。

- 戻した部屋はおばけがいなくなり明るくなる。3つ戻すと学校じゅうのおばけがいなくなる。
- おばけは倒せない。セーブ／ロード／ゲームオーバー／再挑戦あり。

## 検証基準

各ゲーム単独で「来校理由（しゅくだい）→閉じ込め→元に戻す→ドアが開く→帰る→しゅくだいを忘れたオチ」が分かる。
