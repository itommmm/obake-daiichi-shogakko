# PS1版 タップ探索GUI QA

最終更新 2026-11-09

## 実装範囲

- 対象：`ps1.html`, `ps1/style.css`, `ps1/logic.js`, 新規`ps1/adventure-ui.js`
- 主機能：見える対象のマーカー、タップ→衝突を避けて自動移動→調査、黒板／時計／ステージなどの拡大画面、ヒント・アイテム欄
- 維持：固定カメラ、左仮想スティック、WASD、旧タンク操作、アイテム・鍵・暗証番号517、セーブのv2形式
- 外部ライブラリ・外部画像・外部音声は追加しない

## 回帰テスト

- JavaScript構文・スクリプト読み込み順・HTML要素参照・CSS括弧
- `AdventureUI.routeTo`：障害物の迂回・行き止まり時の解除・手動入力による停止
- `AdventureUI.choose`：距離が近い場合の直接調査・離れている場合の自動接近
- アイテム・ドア・黒板・時計のマーカーが、非表示アイテムや他室の対象を誤表示しない
- 拡大画面が閉じられること、ヒントを読み終えるまで表示すること
- アイテム取得後の常設欄更新、セーブ・ロードで調査進行を保持
- 既存`tools/test_ps1.js`の操作・謎解き・エンディング系チェック

## 実ブラウザで行う検査（未確認）

1. iPhoneの縦横向きでタップマーカー・ヒント・アイテム・スティック・「しらべる」が重ならない
2. 子どもが黒板をタップ→自然に近寄る→拡大して調べる、の操作を迷わず使える
3. 教室の机を迂回してこくばんけしへ移動、職員室の机や廊下のロッカーもすり抜けない
4. 自動移動中にスティックを倒すとすぐ止まる。誤タップしても別マーカーを選び直せる
5. 扉と暗証番号517、職員室の時計、体育館ステージからエンディングまで到達できる
6. 既存セーブからの再開・取得アイテムの常設欄・部屋を直した後のマーカーが正しい
7. 視認性、読みやすさ、ヒントの分かりやすさを子どもと確認する

静的・モック試験のみで、実ブラウザ操作や子どものプレイテスト完了とは表記しない。
